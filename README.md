# LastCheck · 出门别忘

> 主动式出门提醒微信小程序：离开任意场所（家 / 公司 / 酒店 / 饭店 / 健身房…），自动推送该场所的「携带清单」。

健忘的人不会主动打开 App，所以一切由系统主动触发 —— **比你自己更早知道你要出门了**。

## ✨ 功能

- 🗺️ **地理围栏触发**：离开场所围栏，自动推送该场所出门清单
- ⏰ **出门习惯定时**：学习你的出门时间，提前 10–15 分钟主动提醒
- 📋 **场所模板库**：家/公司/酒店/饭店/健身房… 一键套用专家清单（社区共建）
- 🌧️ **天气联动**：预报有雨，自动置顶「雨伞」
- 🧠 **忘带统计自适应**：常忘的项自动升级为高嫌疑，常带的项自动降频
- 🔒 **隐私优先**：定位仅用于触发提醒，支持本地存储，开源透明
