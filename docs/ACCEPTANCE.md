# 验收手册

> 每个迭代完成后，按本文档验收。通过标准：对照「操作 → 预期结果」，逐项一致。

## 验收层次

1. **功能验收**（手动）：页面每个可交互元素按下方用例执行
2. **回归验收**（重构阶段）：同一用例在重构前后行为完全一致
3. **代码验收**（自动/检查）：JS 语法通过、持久化正常、提交记录清晰

## 通用前提

- 微信开发者工具编译无红字报错
- 4 个 tab（清单/场所/模板/设置）可正常切换
- 首次打开出现问卷引导；点「开始使用」后进入首页

---

## A. 引导问卷（guide）

| # | 操作 | 预期结果 |
|---|---|---|
| A1 | 首次打开小程序 | 显示问卷第 1 题「你最常从哪出门？」 |
| A2 | 选择「家」 | 弹出地图选点，选点成功后创建场所「家」 |
| A3 | 第 2 题选「必需品」 | 清单自动生成：钥匙/手机/钱包/工卡/充电器/雨伞 |
| A4 | 第 3 题选「开启自动提醒」 | 拉起定位授权请求 |
| A5 | 完成页 | 显示摘要「已为你准备「家」的出门清单（6 件物品）」 |
| A6 | 点「开始使用」 | 进入首页，能看到「家」和清单 |
| A7 | 杀掉小程序重开 | 不再显示问卷，直接进首页 |

## B. 清单页（index）

| # | 操作 | 预期结果 |
|---|---|---|
| B1 | 存在多个场所时切换场所 | 清单切换为对应场所内容 |
| B2 | 点击某物品 | 「未确认」↔「已带」切换，已带项划线变灰 |
| B3 | 点「全部确认已带」 | 所有物品变为已带 |
| B4 | 点「我出门了」 | 出现出门提醒卡片，列出未确认项 |
| B5 | 全部勾选后再点「我出门了」 | 提示「全部确认已带，可以安心出门」 |
| B6 | 无场所时 | 显示空态「还没有场所」+ 去添加按钮 |

## C. 场所页（places）

| # | 操作 | 预期结果 |
|---|---|---|
| C1 | 点「添加场所」 | 地图选点，成功后生成场所卡片（地址 + 半径 100m） |
| C2 | 点场所的「半径」 | 弹出 50/100/200/300/500 米，选择后显示更新 |
| C3 | 点「删除」 | 确认弹窗，确认后场所与清单一并移除 |
| C4 | 删除后回首页 | 首页同步消失该场所 |

## D. 模板页（templates）

| # | 操作 | 预期结果 |
|---|---|---|
| D1 | 页面展示 | 5 个模板：家/公司/酒店/饭店/健身房 |
| D2 | 无场所时点「套用到场所」 | 提示先去添加场所，可跳转场所页 |
| D3 | 有场所时套用 | 弹出场所列表，选择后提示成功并跳首页 |
| D4 | 套用后 | 首页清单变为模板内容，勾选状态重置 |

## E. 设置页（settings）

| # | 操作 | 预期结果 |
|---|---|---|
| E1 | 定位授权状态 | 与系统实际授权状态一致 |
| E2 | 未授权时点「去授权」 | 拉起授权请求，成功更新为已授权 |
| E3 | 点仓库地址 | 复制链接到剪贴板并提示 |
| E4 | 点「清空本地数据」 | 确认后所有场所/清单清空，首页回到空态 |

## F. 持久化

| # | 操作 | 预期结果 |
|---|---|---|
| F1 | 添加场所+勾选物品后杀掉小程序重开 | 数据保留，勾选状态保留 |
| F2 | 清空数据后杀掉重开 | 仍是空态，引导已看过不重复出现 |
